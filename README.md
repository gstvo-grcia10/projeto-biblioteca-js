# 🚀 ApexTech — Loja Conceito (Projeto Bibliotecas JavaScript)

Projeto prático desenvolvido para a disciplina de **Programação Web I**, integrando **3 bibliotecas JavaScript** com funcionalidades distintas para enriquecer a experiência do usuário.

## 📚 Bibliotecas JavaScript Utilizadas

| Biblioteca | Categoria | Para que serve no projeto |
| :--- | :--- | :--- |
| **[Swiper.js](https://swiperjs.com/)** | Interface / Slider Touch | Carrossel dinâmico e responsivo no banner de destaques com suporte a gestos touch e autoplay. |
| **[SweetAlert2](https://sweetalert2.github.io/)** | Modais & Feedback | Notificações discretas (*toasts*) ao adicionar ao carrinho e modal interativo com cálculo total do pedido. |
| **[canvas-confetti](https://www.kirilv.com/canvas-confetti/)** | Animação / Canvas HTML5 | Canhões de confetes disparados no momento em que o cliente confirma o pedido para celebração visual. |

---

## 🛠️ Tecnologias Utilizadas
* **HTML5** (Semântico e responsivo)
* **CSS3** (Variáveis, Flexbox, Grid e Glassmorphism)
* **JavaScript Puro (Vanilla JS)**
* **CDNs Externos** (jsDelivr)

---

## 📂 Estrutura do Projeto
```text
├── index.html                # Página principal da loja interativa
├── style.css                 # Folha de estilos moderna (Dark theme)
├── script.js                 # Lógica de catálogo, carrinho e inicialização das bibliotecas
├── apresentacao.html         # Apresentação interativa de slides no navegador
├── Apresentacao.pptx         # Apresentação de slides para o Microsoft PowerPoint
└── ROTEIRO_APRESENTACAO.md   # Roteiro passo a passo para apresentação em sala
```

---

## 🚀 Como Executar o Projeto Localmente
1. Clone este repositório ou baixe os arquivos.
2. Abra o arquivo `index.html` em qualquer navegador web moderno (Google Chrome, Edge, Firefox, etc.).
3. Para visualizar a apresentação de slides, abra o arquivo `Apresentacao.pptx` no PowerPoint ou acesse `apresentacao.html` no navegador.
