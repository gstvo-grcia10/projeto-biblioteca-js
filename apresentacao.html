Projeto: Bibliotecas JavaScript

Aplicação Web: ApexTech — Concept Gadgets Store
Integração prática de 3 bibliotecas JavaScript de categorias distintas para otimizar a experiência do usuário sem reinventar a roda.

Integrantes: Gustavo Garcia e Bruno Gustavo
3 Bibliotecas Integradas: Swiper.js • SweetAlert2 • canvas-confetti
Visão Geral

As 3 Bibliotecas e Suas Funções

Cada biblioteca cumpre um papel único e essencial na nossa aplicação:

01. Swiper.js

Interface / Slider

Para que serve: Criação de carrosséis touch modernos com gestos para celular e desktop.

Na ApexTech: Apresenta os produtos em destaque com rotação automática sem sobrecarregar o espaço da tela.

02. SweetAlert2

Modais & Diálogos

Para que serve: Substitui os alertas nativos do navegador por caixas de diálogo modernas e acessíveis.

Na ApexTech: Exibe notificações rápidas (Toasts) ao adicionar itens e um modal completo com o resumo do carrinho.

03. canvas-confetti

Animação & Canvas

Para que serve: Física de partículas acelerada por hardware direto no elemento <canvas>.

Na ApexTech: Dispara uma chuva de confetes no momento em que o cliente confirma o pedido, gerando celebração visual.

Implementação Técnica

Como Incluir e Usar no Código

Inclusão direta via CDN no HTML e inicialização direta no JavaScript:

1. Swiper.js (Carrossel)

new Swiper('.mySwiper', { slidesPerView: 3, spaceBetween: 24, loop: true, autoplay: { delay: 3500 } });

2. SweetAlert2 (Modal do Carrinho)

Swal.fire({ title: '🛒 Carrinho de Compras', html: itensHtml, showCancelButton: true, confirmButtonText: 'Finalizar Pedido ✨' });

3. canvas-confetti (Disparo de Partículas)

confetti({ particleCount: 50, spread: 60, origin: { x: 0.1, y: 0.7 } }); // Canhões laterais
